# 🧠 Learned Content & LinkedIn Growth Rules

Эти правила сформированы на основе реальной аналитики постов в профиле (сравнение постов с 526, 218 и 36 поками):

---

## 🎨 1. Правило визуала (The 0.3-Second Rule)
* **Запрещен визуальный шум:** Никогда не помещать мелкий код, длинные листинги или нечитаемый мелкий текст на карточки. В мобильной ленте LinkedIn это превращается в «серую кашу» и игнорируется (пример: пост с 36 показами).
* **Использовать крупные векторные символы и схемы:** Только четкие, контрастные иконки (Telegram -> CDP -> AI, Dirty Data -> Hybrid Engine), крупные разделители и цветовое кодирование (красный = ошибка, зеленый = решение).
* **Лимит слов на картинке:** Максимум **4–6 слов** на всём изображении.

---

## 🎣 2. Правило первых двух строк (Above the Fold)
Первые 2 строки (до кнопки «...Ещё») определяют 90% охвата. Они обязаны содержать один из трех триггеров:
1. **Суперсила / Вау-эффект:** Обещание невероятного контроля или автоматизации (*«Control Antigravity AI IDE directly from your smartphone...»* -> **526 показов**).
2. **Детективная интрига с точной цифрой:** Вызывает страх скрытого бага (*«Why did our pipeline silently drop 14% of data...»* -> **218 показов**).
3. **Жиза / Человеческая боль:** Личный опыт и преодоление (*«I almost lost my mind over...»*).
4. **АНТИ-ПАТТЕРН:** Никаких сухих отчетов из Jira (*«Our API returned 400 Bad Request...»* -> **36 показов**).

---

## 📖 3. Структура сторителлинга (4-фазная арка)
1. **Хук & Проблема:** Личная история, задача из жизни или пет-проекта.
2. **Разбор костылей:** Почему стандартные решения (Regex, Левенштейн, тупой ChatGPT, SQL) провалились на практике.
3. **Инженерный прорыв:** Элегантная гибридная архитектура (C# .NET 8 Clean Architecture + Python + Qdrant / Kafka).
4. **Вопрос к сообществу:** Открытый вопрос для разгона комментариев и алгоритмического буста.

---

## ⚙️ 4. Технический протокол публикации
* При публикации через API всегда использовать эндпоинт **`v2/ugcPosts`** через Python-скрипт во избежание обрезки текста со скобками и спецсимволами.
